The building blocks

1 · Letter cells

One memory cell per symbol (24 letters, 9 digits), each a small 3D lattice of resonant neurons. It is taught like a child: lessons of four or five symbols, big and clear first, then practice lessons with fresh fonts. In practice it learns negative bonds against the images it wrongly claims ("this is not S").

score_c(x) = max_k z( mean activity of slice k ) U_k ← U_k − λ · mean(x it wrongly claimed) λ = 0.1 / (1 + lesson/20)
2 · Word cells

The eye fixates each letter for 3 steps, then saccades. The letter cells' scores are the input current, and the eye's position travels with it. A word cell keeps one input template per eye position, so NO and ON are different words.

I_t = [ relu(score(x at fixation t)) ; position(t) ] word cell template: one per position
3 · Words to things

The word image is shown with its thing, like pointing at a ball and showing "RED". A bond grows between the ringing word cell and the winning thing cell only. No text string is stored anywhere.

A[w, t] += r_w · 1[t = winner] r = relu(scores) / Σ relu(scores)
4 · Grammar

From phrase lessons the model measures which pathway each word position talks about. The first word matches the colour pathway, and the second matches the digit pathway. Each slot then evokes only its own pathway.

G[k, m] = mean cos( r_k A |m , scene |m ) slot 1 → colour (0.74 vs 0.48) slot 2 → digit (0.77 vs 0.50) pick = argmax cos(scene, Σ_k gate_k ⊙ r_k A)
