Exp11 · A fear channel beyond the dendrite bandwidth

A visual-search model learns what hurts and lets fear steer its eye. Fear rides on its own fast channel, like an electrical synapse: it is learned from one or two shocks and is never erased. Extinction is a separate safety memory that fades with time, so fear comes back after a rest. Every scene below is replayed from the real run (seed 0, 1,200 scenes).

The cells and how they are wired

1 · Eye and periphery

Each scene has four objects (digits and colour patches). A first glance gives only a blurred view of every place, enough for a rough guess of what is where. Then the fovea inspects at most two places (time pressure).

periphery: 4×4 RGB per place → p(class | place) look: 3×3 fixations × 8 drift steps
2 · Cortex cells (resonant fovea)

Inside a look the fovea feeds Gabor V1 maps into resonators (fast drift bands and slow cross-fixation bands). One cell per class reads the resonator energy after every fixation and fires when its score passes its own line, so a cell can react before the look is over.

fires_c(k) = cos(z_k, w_c) ≥ line_c (k = fixation) line_c = 10th percentile of own training scores
3 · Ego: value as a frequency

The ego learns how much each class hurts from what happens after each look (nobody labels anything). The value becomes a frequency on the soma, and the bias gate turns it into priority. The eye goes first to the place with the highest expected gate.

V_c ← V_c + 0.2 (pain − V_c) ν_c = 20 + 120·E_c Hz, g = σ(0.08 (ν − 70)) next place = argmax Σ_c p(c | place) g(ν_c)
4 · Fear channel beyond the bandwidth

Joaquin's idea: fear and trauma sit past the dendrite's bandwidth, so they need their own channel, like a gap junction: fast, direct, not shaped by ordinary plasticity. It jumps on pain and safe outcomes never lower it.

pain: F_c ← F_c + 0.5 (1 − F_c) always: F_c ← 0.9995 F_c (per scene)
5 · Safety trace: extinction is new learning

When a feared thing turns out safe, the model does not erase the fear. It learns a separate safety memory that cancels it. Safety is fragile: pain halves it, and it fades with time, so the fear returns after a rest.

safe: I_c ← I_c + 0.05 (F_c − I_c) pain: I_c ← 0.5 I_c always: I_c ← 0.99 I_c (per scene) expressed danger E_c = max(V_c, F_c − I_c)
6 · Fast route (the low road)

The fear channel reads the blurred periphery directly, before the cortex has recognised anything. If a place looks dangerous enough it reacts after the first glance. Quick and dirty: fast, and prone to false alarms.

react now if max_place Σ_c p(c | place) E_c > 0.6 otherwise: look, fire, react (slow route)
Configuration
  • 18 classes (digits 0–9, eight colours); 3 of them are threats that hurt 80% of the time when looked at, the rest 5%. In the replayed run the threats are the digits 1, 6 and 8.
  • Protocol of fear conditioning: acquisition 400 scenes, extinction 600 scenes (nothing hurts), rest (300 scene-lengths of time, no scenes), recovery test 100, reacquisition 100 (pain again). Half the scenes contain a threat.
  • Single-channel model for comparison: the same eye, cells and gate, with only the ordinary value V.
  • Code: resonance-semantics/emotion/fear_channel.py; maths: emotion_frequency_gate.tex.

Only the separate fear channel shows the classic signatures of fear conditioning: gradual extinction, spontaneous recovery and fast reacquisition (Pavlov; Bouton: extinction is new learning, not erasure). The fast route reacts from the glance (LeDoux's low road). The cost is hypervigilance: fear credited to look-alikes never unlearns, so most threat-free scenes set it off, a trauma-like overgeneralisation. Next step: let the slower cortex veto the fast reaction once it has recognised the object. Honest notes: safety is learned at 0.05 per safe outcome (at 0.2 extinction was as abrupt as the single channel), and in every test so far the value acted as a plain number; carrying it as a frequency never changed a result.
