Exp5: can better vision make the resonance agent see natural images?

Eleven methods on CIFAR-10, Imagenette and CIFAR-100: Gabor and learned V1, somatic cells with an axon resonance machine, a deeper somatic stack, feedback from long-term memory, and super labels.

Resonance index, resonance-based semantics and the rule set: Joaquin Philco. Experiments run on CPU in the project's cloud container. Code and result files: resonance-semantics/.

Answer

Not with this kind of structure. Better vision gave the features enough information: a supervised linear readout on the same nodes reaches 54–58%. The agent stays at 31–37% on natural images. One structure per concept stores what the concept looks like on average, and on natural images those averages overlap. The one idea that broke the ceiling was super labels with top-down suppression: when the right set is known, suppressing everything outside it raises CIFAR-100 accuracy from 12% to 42%. The open problem is recognising the set reliably.

The machinery

Every method here keeps the same core and changes one part around it.

RetinaCone-opponent channels: brightness, red, green, blue and yellow ON cells.
V1Oriented edge cells: hand-made Gabor filters, or learned from images.
ResonatorsBanks of damped oscillators read the V1 maps over time; each node is one resonator's energy.
StructuresA concept is a set of nodes that co-resonate above the background, wired across layers.
Agent rulesAsk when unsure, learn the label, sleep: replay, discriminate, prune; axioms, bridges, audits.

Resonance of a structure on an input with node activity a is R = aᵀ W a / ‖a‖². The structure's weights are W = relu(C − Bg) kept at the strongest 2% of edges, where C is the average co-activation on that label's inputs and Bg the co-activation seen before any label (the observation period). The agent answers with the most resonant structure.

Two reference readouts are computed on the same nodes in every run. The template is the class average (what a structure behaves like). The linear probe is a supervised logistic classifier: it shows how much the features carry, and it is not part of the model.

"All labelled" means the oracle labels every image, so only the learning rule is compared. "Asks" means the agent asks only when it doesn't understand (rule 1a).

M2

Nodes listen to a 3×3 grid of image regions

no change

Nodes pooled energy over 4 horizontal strips; the grid version keeps where in the image each energy came from (3,168 nodes instead of 1,408). Every world moved by 2 points or less, so where a node listens was not the limit.

M3

Diagnosis: the agent behaves like a class-average template

found the bottleneck

On CIFAR-10 every front end carries about the same information (linear probe 42–45%). The agent scores like the template (28–32%), not like the linear probe. The gap belongs to the learning rule, not to vision.

M4

Lasting discrimination during sleep

+6 to +14 points

Negative connections were wiped each time a structure was rebuilt. Now, in each sleep, replayed inputs that their own structure doesn't win clearly strengthen their own structure and add the same pattern as negative connections to the rival. These connections survive rebuilds, and a pass that lowers replay accuracy is undone.

With asking, CIFAR-10 reaches 34.6% using 1,801 chosen questions, better than labelling all 3,000 images.

M5

Resolution against amount of data (CIFAR-10)

resolution is not the cause

Joaquin suspected the small images. Shrinking images from 28 px to 8 px costs the linear probe only 3 points, and the template not at all. More images lift the linear probe from 46% (3k) to 58% (25k), while the template stays at 34–35%. Templates have a ceiling that more data does not lift.

M6

Bigger images: Imagenette at 64 and 112 px

49%, no gain from 112 px

The same agent on Imagenette (10 classes, 2,700 training images, 2,000 test images). The agent all labelled reaches 49.4% at 64 px (linear 56.4%) and 49.6% at 112 px. Following Joaquin's point that we learn at full resolution and only later recognise pixelated things, we also trained at full resolution and tested on pixelated images: 28.2% at 64 px and 18.8% at 112 px. The model does not transfer to the coarse view.

M7

Learned V1 by predictive coding

equal to hand-made

Following Jochen Triesch's direction (active efficient coding), V1 is learned instead of designed. Brightness is whitened by a centre-surround retina filter. 32 cells with 11×11 receptive fields are learned by sparse coding: inference settles the code that explains the patch from its prediction error, and each cell learns from the error times its own activity. Nothing is labelled.

M8

Somatic cells with a resonance machine on the axon

below the raster front end

Joaquin's two-compartment cell: a normal time-based somatic function drives learning, and the resonance machine sits on the axon, reading the signal's frequency and feeding back into the soma. Time comes from eye movement: a slow drift loop of 32 steps over the image. V2 somas (256 cells) are learned without labels by sparse coding of V1 activity, integrate their input with a leak, and each axon drives resonators at 4 frequencies. Structures feed back by raising the gain of their member somas.

M10

Feedback from long-term memory into the cells

reinforces wrong guesses

Joaquin's rule: learned structures are long-term memory. When an input makes some of them vibrate, each vibrating structure sends an input back to the cells and resonators that make it vibrate, reinforcing the signal while it is still coming in. The connections are learned from each structure's own replayed examples, and the push is in phase with each resonator. The gated version follows ART: only a clear winner reinforces, its rivals are pushed down, and memory stays silent on a mismatch.

Imagenette, 4,096 nodesNo feedbackStrong feedbackGated, best
Agent, all labelled36.3%34.6%36.9%
Agent, asks36.5%37.9%36.7%

The structures are wrong about two times in three, so reinforcing them reinforces errors. Gating removes the harm but gains under 1 point. Feedback sharpens what a structure already says; it can't make an average discriminate.

M11

Super labels and top-down suppression (CIFAR-100)

works when the set is right

Joaquin: red and blue are part of the set "colours", and we know that by being taught; if "animal" and "leopard" resonate together, suppress the rest. CIFAR-100 has a real hierarchy: 100 classes, 20 supersets (such as large carnivores) and alive / not alive. The oracle names all three levels. Each level grows its own structures, and the links between levels come from the labels taught together.

CIFAR-100, 3,000 test imagesFine (100)Superset (20)Alive / not alive
Flat: most resonant class, no sets12.3%23.6%71.2%
Set structures on their own20.4%66.4%
Sets read through their members25.9%73.9%
Hard suppression from the agent's own set winner8.7%17.6%66.4%
Soft: class + its set structure + its members13.0%25.9%71.6%
Suppression from the true superset (ceiling)42.3%100%100%

Linear probe on the same nodes: 18.5% fine, 29.6% superset. When the set is right, suppressing everything outside it multiplies fine accuracy by 3.5, and no mistake leaves the right set any more. Without help, 87% of the flat model's mistakes are semantically wrong (leopard read as something outside large carnivores). A set structure taught on five different animals is a blurrier average than any one of them, so it picks its set worse than the class winner does. Reading a set through its members (it resonates when leopard, tiger or lion resonate) is better, 25.9% against 20.4%, but not reliable enough to suppress with.

What exp5 leaves for exp6

  • Features are not the limit. Gabor, learned V1, somatic cells and a deep stack all give a linear probe 48–58%. The agent's readout is what caps at about 35%.
  • A concept needs more than one average. One structure per class is a template. Either a concept holds several sub-structures, or its structures must be shaped by what separates it from its rivals (discrimination already gave +6 to +14 points).
  • Sets are powerful once they are right. Suppression from the right superset multiplies fine accuracy by 3.5 and removes every semantically wrong error. Exp6 starts where sets are clean and learnable: letters, numbers and words.
