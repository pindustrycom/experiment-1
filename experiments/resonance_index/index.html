Resonance index, one pixel at a time

Paint a tiny image, watch it become a sequence, and see how each SSM state scores by how well its pole lines up with the frequencies that actually show up in its input.

Ih,n = |g|²⁄L · Σj Sh(νj) ⁄ (1 + r² − 2r cos(νj − θ)),  νj = 2πj⁄L

Spectrum of what the state hears, times how loudly the state rings at each frequency, summed. The denominator is |eiν − λ|², the squared distance from the frequency point on the unit circle to the pole λ = reiθ.

Flattened row by row: time steps

The model never sees the image as 2D. It reads pixel x[t] at step t, row after row. A pattern that repeats every p steps in this strip shows up as energy at frequency 2π⁄p in step 3. Vertical stripes repeat every 2 steps (frequency π); horizontal stripes repeat every 2 rows.

Sequence to channels

A channel is one coordinate of the feature vector the model carries at every time step. The encoder is a linear map applied to each pixel separately: uh[t] = wh·x[t] + bh. With H = 4 channels, one number per step becomes four numbers per step, so the sequence becomes a 4 × L sheet (the 3D view). Your real models use 128 channels.

S4D versus S5: who listens to what

S4D: one small SSM per channel

Each channel h has its own N states with their own poles. State n of channel h only hears uh, so its spectrum is Sh, the spectrum of that channel. That is why the definition carries the index h. Here you see the 4 states of the selected channel (the same pole positions are reused for every channel to keep things small).

S5: one shared SSM for all channels

There is one set of states per layer, shared by every channel. State n hears a mix of all channels: zn[t] = Σh Bn,h uh[t], which is B·u. Its spectrum is the spectrum of that mix, so each state gets its own Sn. In the code this is the line z = einsum("ph,blh->blp", B_bar, u) followed by an FFT.
